# 答辩与演示脚本（约4分钟）

## 0:00–0:30 真实问题
我们研究的是局部损伤与环境刚度变化的混淆。两者都可能降低频率，因此不能简单把频率下降判为损伤。梁鉴用六分区悬臂梁建立一个可完整校核的研究原型，当前所有证据来自仿真。

## 0:30–1:10 AI与力学如何分工
随机树学习模态与候选位置的关系，提出三个可能受损区域。把最多两处损伤的组合从22个减为7个，再通过有限元模型求损伤程度和整体刚度因子。我们保留第4、第5阶模态，它们完全不参与反演，只用于判断模型能否解释新的观测。

## 1:10–1:50 本地演示
运行常规工况，切换第1/3/5阶振型，拖动旋转梁体。解释损伤颜色、估计/真实柱、区间和残差对应同一组计算结果。说明动画幅度与播放速度只是形态示意。

改为健康梁环境变化，展示整体因子改变但没有局部损伤。改为未知附加质量，展示“需要复核”，强调数值仍可展示用于分析，但不能直接当作诊断结论。

## 1:50–2:40 公平实验
三组独立种子、六个测试域，总共720个独立工况。与相同输入的穷举物理反演比较，常规域平均损伤误差0.135与0.150个百分点，在线中位耗时21.6与81.7毫秒。主要优势是减少计算，不能据此声称精度显著优于穷举。纯AI更快，但误差较大。

## 2:40–3:20 不隐藏边界
90%同时区间本次实际覆盖率87.5%，不是已经达到90%的保证。三处损伤超出最多两处的模型假设，附加质量也不在模型中，预测误差都会变大。本轮明显失配被留出残差触发复核，但不能推断所有未知异常都能检出。均匀损伤和环境整体刚度变化从理论上不可辨识。

## 3:20–4:00 可信性与应用
10项力学和数值测试通过；从头生成数据、重新训练两遍，所有非计时结果一致。可以用于力学教学和算法研究，下一步需要做实物梁实验并重新估计观测噪声。源码、模型、原始记录、失败案例和运行说明完整保留。

## 评委可能追问
- AI是否必要？是用于缩减支持集搜索。本小规模问题用穷举也能求解；没有证明AI在所有规模下更有价值。
- 是不是PINN？不是。训练是监督树回归，物理模型在反演和校核阶段耦合，不能换名成PINN。
- 为什么不是全新的算法？基础组件为已有方法，作品贡献是具体问题的组合实现、校核流程与验证。
- 100%定位是否过拟合？仅是120个常规域样本的结果；模型参数和噪声范围有限，不能推广成实际100%。
- 0/120误报能否说明安全？不能。样本有限，且只有健康环境的合成设定。
- 校准覆盖低于90%怎么办？报告实测，扩大独立校准/测试、研究噪声结构；不能在看过测试标签后调宽区间再复用该测试集。
- 为什么不直接用所有模态反演？留出模态用于检查模型失配；若全用于拟合，失配检查需新的独立观测。
- GitHub复制了什么？只进行路线与许可调研，未复制候选项目源码/数据；实际依赖是NumPy、SciPy、scikit-learn等。
- 是否实测？没有。只有仿真验证，实物计划写在独立文件中，未把计划写成成果。
