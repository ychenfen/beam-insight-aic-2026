# 实物验证与冲奖补强

当前作品是仿真验证的研究原型。冲奖最有价值的下一步是证明合成模型在实物上仍能工作，不能以更漂亮的图代替这项证据。

## 最小可执行试验
- 使用一根可重复夹持的细长铝梁，实测长宽厚、密度或总质量；记录夹持长度和螺栓拧紧方法。
- 先做健康梁，使用小锤激励；激光位移计或质量影响可校正的小型加速度计在6个位置采集，至少3次重复。
- 数据采样率须高于第五模态的2倍，并留抗混叠裕量；记录传感器型号、采样率、采样时长、频率分辨率。
- 用频响拟合或模态识别提取前5阶频率/振型。传感器移动测量需固定参考通道保证相位一致。
- 先比较健康模型，检查模态排序/符号、MAC、频率误差；模型尚未通过时不得直接诊断。
- 局部刚度变化用可控连接段/可替换试件实现，由实验负责人决定安全方案。不把附加质量当作已知刚度损伤。
- 温度和夹具变化分组记录；整体刚度因子不等价于温度测量，温度引起的边界变化可能不被该因子解释。
- 预留20%以上独立工况，冻结参数后再揭示标签；保留仪器原始文件，不根据测试结果反复重选传感器位置。

## 接收标准（预先约定的计划，尚未达成）
1. 三次重复的健康模态可对齐，频率变异系数可量化。
2. 校准/测试分开；报告定位、损伤幅度误差、健康误报与拒判。
3. 与相同输入的穷举反演基线比较，并单列模型误差。
4. 原始波形、测量照片、试验记录和同意用于比赛的说明齐全。
